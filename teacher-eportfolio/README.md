# ملف الإنجاز الإلكتروني للمعلم

صفحة ملف إنجاز مرتبطة بقاعدة بيانات **MySQL** (تُدار من **phpMyAdmin**):

- **الزوار** يشاهدون جميع الأقسام والملفات **للقراءة فقط**.
- **المسؤول (الأدمن)** وحده يسجّل الدخول ويعدّل كل شيء: البيانات والصور والملفات والإعدادات.

## محتويات المجلد

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة نفسها |
| `index.php` | يعرض الصفحة مع بطاقة معاينة الرابط (الاسم والصورة) عند المشاركة في واتساب |
| `admin.html` | رابط مختصر لصفحة دخول المسؤول |
| `api.php` | الوسيط بين الصفحة وقاعدة البيانات (يتحقق من صلاحية المسؤول قبل أي تعديل) |
| `config.php` | ✏️ **الملف الوحيد الذي تعدّله**: بيانات قاعدة البيانات وكلمة مرور المسؤول |
| `database.sql` | جداول قاعدة البيانات والبيانات الافتراضية (للاستيراد من phpMyAdmin) |
| `uploads/` | تُحفظ فيه الصور وملفات Word وPDF المرفوعة |
| `.htaccess` | حماية ملفات الإعدادات ومنع تشغيل أي سكربت داخل `uploads` |

## جداول قاعدة البيانات (جدول لكل قسم)

| الجدول | ماذا يحفظ |
|---|---|
| `ep_settings` | إعدادات الموقع: اسم الموقع، العام الدراسي، العبارة، الألوان، الخط، عناوين الأقسام، الشعار |
| `ep_profile` | السيرة الذاتية (الاسم، المدرسة، المؤهل، ...) والصورة الشخصية |
| `ep_cards` | بطاقات «الأساسيات» السبع: العنوان، الوصف، الصورة، الإظهار/الإخفاء |
| `ep_courses` | النمو المهني: الدورات والبرامج والساعات |
| `ep_certificates` | شهادات الشكر وشهادات الدورات |
| `ep_folders` | مجلدات الأداء: الاسم، الأيقونة، الترتيب، الملاحظات |
| `ep_folder_points` | العناصر الفرعية لكل مجلد وحالة إنجازها ✓ |
| `ep_folder_items` | الشواهد المرفوعة في كل مجلد (روابط، صور، Word، PDF) |
| `ep_login_attempts` | حماية تسجيل الدخول من التخمين |

يمكنك تصفح أي جدول من phpMyAdmin، لكن يُفضَّل التعديل من داخل الصفحة بعد تسجيل الدخول.

## كيف يدخل المسؤول ويعدّل؟

1. افتح `رابط-موقعك/admin.html` — أو اضغط زر **🔒 دخول المسؤول** أعلى الصفحة.
2. اكتب اسم المستخدم وكلمة المرور الموجودين في `config.php`.
3. بعد الدخول يظهر **شريط المسؤول** أسفل الشاشة، وتظهر أزرار الرفع والحذف في كل قسم:
   - **⚙️ الإعدادات**: الاسم، المدرسة، الألوان، الخطوط، البطاقات، إضافة/تعديل/حذف المجلدات.
   - **بطاقات الأساسيات**: زر «رفع صورة»، وجدولا السيرة الذاتية والنمو المهني قابلان للكتابة.
   - **المجلدات**: افتح أي مجلد ثم ارفع (رابط / صور / Word / PDF) وضع ✓ على العناصر واكتب الملاحظات.
   - كل تعديل يُحفظ تلقائياً في قاعدة البيانات (يظهر «محفوظ» أعلى الصفحة).
4. **👁️ معاينة كزائر** تُخفي أدوات التعديل مؤقتاً لترى الصفحة كما يراها الزوار — اضغط **رجوع للتعديل** للعودة. (هذا الزر ليس تسجيل دخول.)
5. **خروج** لتسجيل الخروج.

> إذا فتحت `index.html` مباشرة من جهازك (بدون استضافة PHP) تعمل الصفحة في **وضع تجريبي**: يظهر زر 🔒 دخول المسؤول أيضاً، ويُقبل فيه أي اسم وكلمة مرور، والتعديلات تُحفظ في المتصفح فقط. كلمة المرور الحقيقية من `config.php` تُطلب بعد الرفع على الاستضافة.

## مميزات إضافية

- **إخفاء الفارغ عن الزوار:** البطاقات والمجلدات التي لا تحتوي شيئاً لا تظهر للزوار (وتظهر لك كمسؤول لتعبئتها).
- **تعديل الشاهد:** زر ✏️ بجانب كل شاهد وشهادة لتغيير الاسم وإضافة وصف يظهر للزوار.
- **الترتيب بالسحب:** اسحب أيقونة ⋮⋮ بجانب الشاهد (أو الشهادة) لإعادة ترتيبها — يعمل على الجوال أيضاً.
- **عرض الملفات داخل الصفحة:** ملفات PDF تُعرض مباشرة، وملفات Word عبر عارض أوفيس بعد نشر الموقع على الإنترنت.
- **مشاركة برمز QR:** زر الرمز أعلى الصفحة: رابط للنسخ، مشاركة واتساب، تنزيل أو طباعة بطاقة الرمز.
- **تصدير PDF:** زر PDF أعلى الصفحة يجهّز ملفاً بغلاف وفهرس وكل قسم في صفحة؛ اختر «حفظ بصيغة PDF» في نافذة الطباعة.
- **تغيير بيانات الدخول:** ⚙️ الإعدادات ← أدوات ← بيانات الدخول (تُحفظ مشفّرة في قاعدة البيانات وتحل محل config.php).
- **نسخة احتياطية كاملة (ZIP):** ⚙️ الإعدادات ← أدوات ← تنزيل نسخة / استعادة نسخة — تشمل البيانات وجميع الصور والملفات.

## خطوات التركيب على الاستضافة (cPanel)

1. **أنشئ قاعدة بيانات**
   من cPanel ← **MySQL® Databases**:
   - أنشئ قاعدة بيانات جديدة (مثلاً `portfolio`).
   - أنشئ مستخدماً بكلمة مرور قوية.
   - اربط المستخدم بالقاعدة وامنحه **ALL PRIVILEGES**.

2. **استورد الجداول**
   افتح **phpMyAdmin** ← اختر قاعدة البيانات من القائمة الجانبية ← تبويب **استيراد (Import)** ← اختر الملف `database.sql` ← **تنفيذ (Go)**.
   (إذا تخطيت هذه الخطوة سيُنشئ `api.php` الجداول تلقائياً عند أول تشغيل. وإذا كانت لديك بيانات من النسخة السابقة في جدول `ep_data` فستُنقل تلقائياً إلى الجداول الجديدة ويُحتفظ بالقديم باسم `ep_data_backup`.)

3. **عدّل `config.php`**
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'اسم قاعدة البيانات كاملاً');   // غالباً بالشكل: cpaneluser_portfolio
   define('DB_USER', 'اسم المستخدم كاملاً');          // غالباً بالشكل: cpaneluser_dbuser
   define('DB_PASS', 'كلمة مرور قاعدة البيانات');

   define('ADMIN_USERNAME', 'admin');                  // اسم دخول المسؤول
   define('ADMIN_PASSWORD', 'كلمة-مرور-قوية-هنا');      // لن يعمل الدخول ما دامت CHANGE_ME
   ```

4. **ارفع الملفات**
   من cPanel ← **File Manager** ← `public_html` (أو مجلد فرعي مثل `public_html/portfolio`) ← ارفع جميع محتويات هذا المجلد كما هي، بما فيها `uploads` وملفات `.htaccess`.
   تأكد أن مجلد `uploads` قابل للكتابة (الصلاحيات `755`).

5. **جرّب**
   - افتح رابط موقعك: ستظهر الصفحة للزوار للقراءة فقط.
   - افتح `admin.html` وسجّل الدخول كما في القسم السابق.

## الربط مع منصة المعلمة

يعرض ملف الإنجاز شواهد [منصة المعلمة](../teacher-platform/) داخل المجلد المطابق لكل معيار من معايير الأداء الثمانية (الإدارة الصفية، خطة التعلم، تحسين النتائج، أولياء الأمور، التقنيات، البيئة التعليمية، التقويم، تحليل النتائج).

1. في `config.php` **بالمنصة** ضع مفتاحاً سرياً طويلاً في `PORTFOLIO_KEY`.
2. في ملف الإنجاز: **الإعدادات ← أدوات ← الربط مع منصة المعلمة**، اكتب رابط المنصة ونفس المفتاح، ثم **حفظ واختبار**.

- الخادم هو الذي يجلب الشواهد، فلا يصل المفتاح إلى المتصفح ولا يُحفظ في GitHub.
- تُحفظ نسخة مؤقتة تتجدد كل 10 دقائق، وإذا تعذر الوصول للمنصة تبقى آخر نسخة ظاهرة.
- يتعامل تلقائياً مع فحص الحماية في استضافة InfinityFree.

## الأمان

- كل عمليات الحفظ والرفع والحذف تُرفض من الخادم إن لم يكن المستخدم مسؤولاً مسجّل الدخول، حتى لو حاول أحد تجاوز الواجهة.
- طلبات التعديل محمية برمز CSRF، وملف تعريف الجلسة `HttpOnly` و`SameSite=Strict`.
- بعد 5 محاولات دخول خاطئة يُقفل الدخول من نفس الجهاز 15 دقيقة.
- يُقبل رفع الصور وWord وPDF فقط، مع التحقق من محتوى الملف، وتُحفظ بأسماء عشوائية.
- لمزيد من الأمان يمكنك وضع ناتج `password_hash('كلمتك', PASSWORD_DEFAULT)` (يبدأ بـ `$2y$`) بدلاً من كلمة المرور الصريحة في `config.php`.
- لا ترفع `config.php` بعد تعبئته إلى مستودع عام على GitHub.

## ملاحظات

- إذا فتحت `index.html` مباشرة من جهازك (بدون خادم PHP) تعمل الصفحة في **وضع تجريبي** وتُحفظ التعديلات في المتصفح فقط.
- حجم الرفع الأقصى يُضبط من `MAX_UPLOAD_MB` في `config.php`، ويجب ألا يتجاوز `upload_max_filesize` و`post_max_size` في إعدادات PHP بالاستضافة (cPanel ← **Select PHP Version** ← Options أو **MultiPHP INI Editor**).
- النسخ الاحتياطي: من ⚙️ الإعدادات ← أدوات ← **تنزيل نسخة** (ملف ZIP كامل بالبيانات والملفات)، ويمكن أيضاً تصدير قاعدة البيانات من phpMyAdmin ← **تصدير (Export)**.
- الترقية: عند رفع نسخة أحدث من الملفات تُحدَّث جداول قاعدة البيانات تلقائياً دون فقدان البيانات.
- إذا نسيت كلمة المرور المحفوظة من داخل الموقع: احذف الصفين `_admin_user` و`_admin_hash` من جدول `ep_settings` في phpMyAdmin لتعود بيانات `config.php`.
